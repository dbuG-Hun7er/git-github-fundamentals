# 🐙 Git & GitHub Fundamentals

**Práticas de controle de versão e gerenciamento de repositórios utilizando Git e GitHub.**

## 📌 Sobre o projeto

Este repositório contém um exercício prático desenvolvido durante os estudos na EBAC, com foco nos fundamentos de Git e GitHub.

A atividade consiste em clonar um repositório, editar um arquivo de texto, registrar as alterações por meio de commits e compartilhar o repositório no GitHub.

O objetivo é desenvolver familiaridade com o fluxo básico de controle de versão e gerenciamento de código-fonte.

## 🎯 Objetivos

- Compreender o funcionamento do Git e GitHub.
- Praticar a clonagem de repositórios.
- Editar e atualizar arquivos versionados.
- Registrar alterações utilizando commits.
- Compreender o histórico de modificações.
- Criar e gerenciar repositórios no GitHub.
- Compartilhar projetos e alterações.

## 💻 Principais comandos Git

```bash
# Clonar um repositório
git clone <repository-url>

# Verificar alterações
git status

# Adicionar arquivos
git add .

# Registrar alterações
git commit -m "Modificando o arquivo de dados"

# Enviar alterações para o GitHub
git push
```
